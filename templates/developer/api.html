POST /api/solve

Solves any valid 3x3 Rubik's cube state or scramble string using Kociemba Two-Phase algorithm.

Request Payload: {"scramble": "R U R' U' F' U2"}
Response: {"success": true, "solution": "U2 F U R U' R'", "moves": 6, "time_taken_ms": 0.35}
GET /api/scramble

Generates official WCA compliant pseudorandom scramble sequences.

Response: {"success": true, "scramble": "D2 R F2 U' R2 B' L2 ...", "length": 20}
GET /custom-cubes/api/<id>

Retrieves full 10-shape archetype data, color schemes, and sticker states for client studios.
